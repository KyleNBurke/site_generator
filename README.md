# Static Website Generator

This is the code repository for the site generator that created [kyleburke.github.io](kylenburke.github.io).

The generator produces articles from markdown files. It supports syntax highlighting in code blocks as well as [math ml](https://developer.mozilla.org/en-US/docs/Web/MathML). A good example of these can be see on the [Generating Signed Distance Fields Article](https://kylenburke.github.io/article/sdf/article.html) which was generated from the markdown file in [articles/sdf/article.md](articles/sdf/article.md).
